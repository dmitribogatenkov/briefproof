A small expense tracker I run on my own laptop, in the browser, with no account
and no internet connection needed.

I add an expense with a date, an amount, a description and a category. Amounts
are typed with a comma as the decimal separator (12,50) and shown the same way
everywhere, with the euro sign after the number.

If I add an expense with the same date, amount and description as one that is
already there, ask me whether I really want it twice before saving it.

The list shows the current month by default, newest first, with the month's
total at the top. I can go back and forward one month at a time.

I can export the month I am looking at as a real .xlsx file that opens in Excel
with the amounts as numbers, not text. Not a CSV.

Expenses older than 24 months are removed automatically when the app starts,
and the app tells me how many it removed.

Everything is saved in a single file in the project folder, so I can back it up
by copying that one file.
